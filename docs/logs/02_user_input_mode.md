# 02. 3×3 사용자 입력 모드

## 목적

사용자가 3×3 필터 A, 필터 B, 패턴을 직접 입력하고 MAC 연산 결과를 비교하여 A/B 또는 판정 불가 결과를 출력하는 기능을 구현했습니다.

## 실행

```bash
python3 main.py
```

프로그램 실행 후 다음 메뉴에서 `1`을 선택합니다.

```text
[모드 선택]
1. 사용자 입력 (3x3)
2. data.json 분석
선택: 1
```

## 테스트 입력

### 필터 A — Cross

```text
0 1 0
1 1 1
0 1 0
```

### 필터 B — X

```text
1 0 1
0 1 0
1 0 1
```

### 입력 패턴 — X

```text
1 0 1
0 1 0
1 0 1
```

이 경우 필터 A보다 필터 B의 MAC 점수가 높게 계산되므로 최종 판정은 `B`가 됩니다.

## MAC 계산 방식

프로그램은 각 위치의 값을 서로 곱한 후 결과를 누적합니다.

```text
score += pattern[i][j] * filter[i][j]
```

3×3 배열은 총 9개의 위치를 순회합니다.

## 입력 검증

사용자 입력 모드에서는 다음 항목을 검사합니다.

- 한 행에 입력된 숫자의 개수가 3개인지 확인
- 숫자로 변환할 수 없는 값이 포함되어 있는지 확인
- 잘못된 행은 저장하지 않고 다시 입력

입력 오류 검증은 기능 요구사항이므로 별도로 테스트할 수 있지만, 최종 실행 결과 스크린샷에서는 정상 동작 화면을 중심으로 제시합니다.

## epsilon 동점 처리

두 점수의 차이가 다음 조건을 만족하면 단순한 A/B 판정을 하지 않고 `UNDECIDED`로 처리합니다.

```text
abs(score_a - score_b) < 1e-9
```
